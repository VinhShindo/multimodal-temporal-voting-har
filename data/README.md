# Data

- `raw/`       : dữ liệu MMAct gốc (giữ nguyên); xem [raw/README.md](./raw/README.md) để biết cấu trúc và kiểm kê hiện tại.
- `processed/` : dữ liệu tạo sau bước preprocess và manifests dùng cho các protocol train/val.

`processed/` được sinh từ dữ liệu trong `raw/`; không chỉnh sửa trực tiếp dữ
liệu gốc để tạo kết quả thí nghiệm.
